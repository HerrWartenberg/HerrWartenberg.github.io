# herrwartenberg.github.io

Startseite mit allen digitalen Escape Rooms und Lernspielen (Erdkunde, Flora-Realschule Düsseldorf).

**Adresse:** https://herrwartenberg.github.io/

## Aufbau
- `index.html` – Übersicht mit Links zu allen Räumen
- Neue Escape Rooms kommen als **Unterordner** in dieses Repository, z. B. `vulkane9/index.html` → https://herrwartenberg.github.io/vulkane9/ (kein neues Repo, keine Pages-Aktivierung nötig).
- `orbis-3d/` – 3D-Fassung von ORBIS (gebaut in `~/claude-projekte/escape-rooms/orbis-3d`, dort `npm run build`, dann `dist/index.html` hierher kopieren).
- `geheimschriften6/` – Museum der Geheimschriften (Informatik Kl. 6, 3D; gebaut in `~/claude-projekte/escape-rooms/krypto-6`, dort `npm run build`, dann `dist/index.html` hierher kopieren).
- Ältere Räume liegen in eigenen Repositories und bleiben unter ihren Adressen erreichbar: `klimawandel8`, `weltbevoelkerung10`.

Alle Seiten: keine externen Ressourcen, keine Cookies, kein Tracking. Erstellt mit Unterstützung von Claude (Anthropic).
